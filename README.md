# 🚀 Team Task Manager

A full-stack Team Task Management system with role-based access (Admin & Member).  
This application helps teams manage projects, assign tasks, and track progress efficiently.

---

## ✨ Features

- 🔐 Authentication (Login/Register)
- 👤 Role-based access (Admin / Member)
- 📁 Create and manage projects
- ✅ Assign tasks to team members
- 📊 Dashboard with task stats (Total, Completed, Pending)
- ⏰ Due date tracking
- 🟢 Task status management

---

## 🛠 Tech Stack

**Frontend:**
- React.js
- Axios
- CSS / Modern UI

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB (Atlas)
